Add Client form setup

Set the three Add Client pages' fields: each field's column name, input type, and whether it is required. The fields the client was built with are the defaults — their names can change, but their type cannot. Every field has a Delete button on its right, except the structural ones (client name, contact name, SOF number, service, activation date), which stay required and cannot be deleted. Deleting a field also deletes everything entered in it; a deleted default can be added back with + Add field under the same name, but its old values are gone.

Good to know

A field you delete takes its entered values with it — a deleted default field can be added back with + Add field under the same name, but its old values are gone. A Dropdown field only accepts one of its listed options. A Yes-No field is a Yes/No choice. Changing a field here changes the Add Client form for every Sales user from now on; clients already sent keep the values they were made with.
