About mail

The portal sends mail when a user creates an application: the creator gets a mail saying they created it, and the step user whose turn it is gets a mail saying it is waiting for their approval. When a step approves, the next step user gets the same mail. A user who has not added their mail in My settings gets no mail. If these settings are empty, no mail is sent at all.

The password is stored in the portal's database. For Gmail, Google does not accept the normal account password for sending — use an App Password from Google instead.
