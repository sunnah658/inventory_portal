What happens here

A deleted record, Department Database row, invoice or item request can be restored any time within {{ days }} days. After that it is erased for good. A deleted Department Database tab is restored from the Others tab, with its rows.

Deleting a user for good asks: "You want to delete this user all work from the portal too?" — Yes erases the work at once, No leaves the work until the {{ days }} days end. A purged user can never be restored.

Users removed with No leave the Users tab but their data stays in the database — they are listed in the 'Deleted users' data' tab (portal admin only). Tick the names there and click Delete all to erase a user and ALL their data at once, without waiting for the {{ days }} days.

A permission user can restore anything, but only the portal admin can erase a record, row, invoice, request or tab that a permission user deleted.
