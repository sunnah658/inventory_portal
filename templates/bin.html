What happens here

A deleted record, Department Database row, application letter, invoice or item request can be restored any time within {{ days }} days. After that it is erased for good.

Deleting a user for good asks: "You want to delete this user all work from the portal too?" — Yes erases the work at once, No leaves the work until the {{ days }} days end. A purged user can never be restored.

A permission user can restore anything, but only the portal admin can erase a record, row, application, invoice or request that a permission user deleted.
