How sharing works

The tab appears in their Department Database as {{ tab['name'] }}({{ dept['name'] }}).

They see only the All rows view — no My rows, no Deleted.

View means see the rows. Edit means edit the existing rows only — they cannot add or delete a row, and cannot change the tab's columns or settings.

A department grant reaches everyone in that department. A user grant reaches only that one person.

Only the department admin of {{ dept['name'] }} can change this page.
