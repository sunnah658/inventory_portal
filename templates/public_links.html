Public QR links

QR codes anyone can scan without logging in. Each has a unique random code (HRC-#####, for example HRC-48392) that any logged-in portal user can type in the search bar. New QRs get a random 5-digit code; old QRs keep their sequential number internally and were given a random code on upgrade. Create one for a single record on the record page, or tick many records in a list and choose "Public QR".
