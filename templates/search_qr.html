How codes work

Every public QR has a unique code starting with HRC- and a random 5-digit number. The code is only a sharing and searching key — it is not the record or invoice number.

Scanning a QR or searching a code needs a login. If the owner makes a new scan link, the old code stops working. An invoice code opens the invoice page, a request code opens the request page, and a Department Database row code opens that row.
