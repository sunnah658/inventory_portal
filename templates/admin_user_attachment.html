User Attachment Access

Tick a user to let them upload attachments on their own My records page — they can then add an Attachment column to their Mine tab and put a file in it. Unticked users cannot add an Attachment column (they can still add all other column types). The portal admin can always do this. The same tick still lets a dept admin create attachment columns in the Department Database.
