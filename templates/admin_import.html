Import users from a CSV file

Make the file in Excel and save it as "CSV UTF-8". The first row must be: full_name,username,department,role,password

Only full_name, username and department are required. Leave role empty for a normal user. Leave password empty and the portal creates a temporary password for each person. A department that does not exist yet is created (with starter columns if its name matches a template). Existing usernames are skipped.

Download a sample file

After the import

New users get a temporary password and must change it at first login. The result page shows the passwords once — download or print them there, they are not shown again. Accounts imported here can log in at once.
